# Iago Santos Pardo - CV Website

## 🌟 About

This is my personal CV website showcasing my professional experience as a Senior DevOps Engineer. The website is built with modern web technologies and features a responsive design with multi-language support.

## 🚀 Features

- **Multi-language Support**: Available in English, Spanish, Galician, and French
- **Responsive Design**: Optimized for all devices (desktop, tablet, mobile)
- **Interactive Elements**: 
  - Animated counters and progress bars
  - Lightbox portfolio gallery
  - Smooth scrolling navigation
  - Contact form with email integration
- **Modern UI/UX**: Clean, professional design with smooth animations
- **SEO Optimized**: Meta tags, structured data, and accessibility features

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and modern structure
- **CSS3**: Advanced styling with animations and responsive design
- **JavaScript (ES6+)**: Interactive functionality and language switching
- **Bootstrap**: Responsive grid system and components
- **AOS (Animate On Scroll)**: Scroll-triggered animations
- **Font Awesome**: Icon library

## 🌐 Language Support

The website supports 4 languages with URL routing:

- **English** (default): `/` or `/en`
- **Spanish**: `/es`
- **Galician**: `/gl` (with pirate flag 🏴‍☠️)
- **French**: `/fr`

Language preferences are saved in localStorage and the URL updates automatically when switching languages.

## 📱 Responsive Design

The website is fully responsive and optimized for:

- **Desktop**: Full experience with all animations and effects
- **Tablet**: Adapted layout with touch-friendly interactions
- **Mobile**: Optimized for small screens with collapsible navigation

## 🎨 Design Features

- **Hero Section**: Animated background with particle effects
- **Skills Section**: Interactive progress bars with smooth animations
- **Portfolio**: Filterable gallery with lightbox functionality
- **Contact Form**: Integrated email functionality
- **Language Selector**: Elegant dropdown with flag icons

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/isantospardo/isantospardo.github.io.git
   cd isantospardo.github.io
   ```

2. **Serve the website**:
   ```bash
   # Using Python
   python3 -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using any other static file server
   ```

3. **Open in browser**:
   Navigate to `http://localhost:8000`

## 🔧 Customization

To customize this CV website for your own use:

1. **Update personal information** in `index.html`
2. **Modify the skills section** with your own skills and percentages
3. **Replace portfolio images** in the `portfolio/` directory
4. **Update contact information** and social media links
5. **Customize colors and styling** in the CSS files
6. **Add or modify languages** in the `translations` object in `epic.js`
